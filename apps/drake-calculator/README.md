# La calculadora de Drake

Aplicación interactiva para explorar la ecuación de Drake y visualizar una
estimación de civilizaciones comunicantes en la Vía Láctea.

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación se publica como exportación estática bajo
`/apps/drake-calculator/`. También admite una compilación `standalone` mediante
el `Dockerfile`.

La imagen galáctica fue obtenida con
[`mw-plot`](https://milkyway-plot.readthedocs.io/) y acredita a
NASA/JPL-Caltech/R. Hurt (SSC/Caltech).
